WORLD QUIZ - deploy steps (all free)
1. Netlify: drag this folder onto app.netlify.com/drop  (or GitHub repo -> Netlify as usual)
   Cloudflare Pages / GitHub Pages / Vercel also work: upload the same files.
2. Open the live https link on a phone -> "Add to Home Screen" (PWA).
3. APK: paste the live URL into webintoapp.com.
4. Ads: paste your Adsterra banner code into #ad-slot in index.html and remove 'hidden'.
